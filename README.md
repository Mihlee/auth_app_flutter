# Track 2 Flutter & Firebase Authentication App

A clean, responsive, cross-platform Flutter application integrated with Firebase Authentication, built to fulfill Track 2 project requirements.

---

##  Features

* **User Registration**: Create new accounts securely using Email and Password.
* **User Authentication**: Sign in existing users with Firebase Auth.
* **Session Persistence**: Stream-based authentication handling that maintains user sessions across application reloads.
* **Dashboard Screen**: Protected home route showing the authenticated user's email address upon successful login.
* **Sign Out**: One-click session termination and automatic routing back to the Auth screen.
* **Error Handling**: On-screen feedback for invalid credentials or missing fields.

---

##  Tech Stack & Dependencies

* **Framework**: [Flutter SDK](https://flutter.dev/)
* **Backend as a Service**: [Firebase](https://firebase.google.com/)
* **Core Libraries**:
  * `firebase_core` - Core initialization for Firebase services.
  * `firebase_auth` - Authentication API integration.
